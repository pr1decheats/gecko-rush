# Android 2.1: установка и Google Play

Актуальный файл: GeckoRush-2.1.apk, версия2.1.0, versionCode3, package org.geckorush.game. Android7/API24+, target API36, ARM32/64. Используется release engine Godot4.6.3. В APK нет запрошенных разрешений, android:debuggable не включён. Проверены подписьv2/v3, прежний сертификат, ZIP CRC, 16KB ZIP alignment и LOAD alignment обеих ARM64 библиотек. APK подписан прежним тестовым ключом для обновления2.0 без удаления локальных данных.

## Почему может появляться предупреждение

Браузер может предупреждать о формате APK, Android — об установке вне магазина, Play Protect — о неизвестном приложении. По описанию без точного сообщения нельзя определить причину или исключить антивирусное срабатывание. Корректная подпись и контрольная сумма подтверждают целостность, но не являются антивирусным заключением. Тестовая подпись не является магазинной; обещать исчезновение предупреждений после этой сборки нельзя.

## Что нужно для Google Play

1. Зарегистрировать Play Console: US$25 однократно и верификация владельца. Сама разработка/сборка Android бесплатна.
2. Перед магазинным выпуском создать отдельный недебажный upload key, хранить его приватно и включить Play App Signing. Текущий тестовый APK не менять молча на новый сертификат: при том же package он не сможет обновить уже установленную тестовую версию напрямую. Заранее решить перенос прогресса.
3. Собрать release AAB через официальный Gradle template Godot4.6.3, проверить bundletool/jarsigner, manifest/API36 и16KB совместимость сгенерированных APK. В этом обновлении собран APK; магазинный AAB пока не создавался.
4. Подготовить карточку, иконку, скриншоты, контакты, возрастной рейтинг, Data Safety и политику конфиденциальности, отражающую финальную версию. Сейчас прогресс локальный, рекламы/аналитики/сетевых SDK в игре нет.
5. Для новых личных аккаунтов — закрытое тестирование минимум12 участников непрерывно14дней и заявка на production access. Сам минимум не гарантирует одобрение.

Официальные источники: [регистрация](https://support.google.com/googleplay/android-developer/answer/6112435), [тестирование](https://support.google.com/googleplay/android-developer/answer/14151465), [подпись](https://support.google.com/googleplay/android-developer/answer/9842756), [target API](https://support.google.com/googleplay/android-developer/answer/11926878), [16KB](https://developer.android.com/guide/practices/page-sizes), [Godot Android](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_android.html).

На реальном телефоне этот APK пока не запускался. Компьютерные проверки игровой сцены и синтетические ScreenTouch не заменяют проверку устройства, производительности и системных прерываний.
