# Сборка unsigned IPA без собственного Mac

[Ручной workflow GitHub Actions](../.github/workflows/ios.yml) успешно собрал настоящую **неподписанную IPA 2.2.0 (4)** на облачном Mac 12 ноября 2026 года: [запуск 43295517584](https://github.com/pr1decheats/gecko-rush/actions/runs/43295517584), исходный commit `0fa8ddcdb156725c6d959d31ba59c58539d67061`.

Файл `GeckoRush-2.2-unsigned.ipa` имеет размер **27,202,757 байт**, предназначен для физического iPhone с **iOS 14+**, arm64, портретной ориентации. [Скачать IPA](https://gecko-rush-godot-6e42.honedgrackle2.chatgpt.site/#download-ios). Сборка и содержимое файла проверены; подпись, установка и запуск на настоящем iPhone ещё не выполнялись.

```text
SHA-256: 4345bb56c97123ee659adf9ae7bfd5404bfa96b34e8f7393d1fd705468f2e96d
```

## Что потребуется

- GitHub-репозиторий с этим проектом и включёнными Actions. Сам файл workflow должен находиться в основной ветке, чтобы появился ручной запуск.
- Публичный репозиторий и разрешение владельца на публикацию исходников. Стандартный GitHub-hosted runner `macos-15-intel` в публичном репозитории бесплатен. У job добавлена проверка `github.event.repository.private == false`: в частном репозитории она пропускается до выделения Mac, чтобы не расходовать платный баланс.
- Для последующей установки — компьютер с Windows, iPhone и выбранный инструмент подписи, например [Sideloadly](https://sideloadly.io/) или [AltStore Classic](https://altstore.io/).

У рецепта только `workflow_dispatch`: публикация кода и создание pull request сами сборку не запускают. У job тайм-аут **30 минут**, доступ к репозиторию — только `contents: read`. Установка ключей Apple, сертификатов и GitHub Secrets для этой неподписанной сборки не требуется. Бесплатность стандартных runner в публичных репозиториях описана в [документации GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).

## Что делает workflow

1. Читает текущий commit через checkout и скачивает официальный Godot **4.6.3 stable для macOS universal** и официальный пакет экспортных шаблонов. SHA-256 обоих файлов зафиксированы по данным релиза. Из большого пакета извлекается только `ios.zip`.
2. Создаёт временную копию исходников через `git archive`. Исходный checkout не изменяется. [CI helper](../scripts/ci/export_ios.gd) проверяет, что запущен именно во временной папке, и настраивает только её экспортный пресет.
3. Импортирует ресурсы и экспортирует `GeckoRush.xcodeproj`, `.pck`, `.xcframework` и прочие файлы через официальный экспортёр Godot. Минимальная целевая iOS — **14.0**, bundle identifier — `org.geckorush.game`.
4. Вызывает `xcodebuild` с SDK `iphoneos`, схемой `GeckoRush` и конфигурацией Release. Подпись явно отключена параметрами `CODE_SIGNING_ALLOWED=NO` и `CODE_SIGNING_REQUIRED=NO`; обновление provisioning не запрашивается.
5. Находит приложение в `DerivedData/Build/Products/Release-iphoneos`, читает его `Info.plist` и проверяет bundle identifier, iPhoneOS, наличие игрового `.pck` и настоящего исполняемого файла **Mach-O arm64 EXECUTE**. Папка исходников или одна статическая библиотека эту проверку не проходят.
6. Копирует собранное `.app` в `Payload/`, создаёт `GeckoRush-unsigned.ipa`, проверяет ZIP и вычисляет SHA-256. Загружает IPA и `build-info.txt` в артефакт **GeckoRush-unsigned-ipa**, который хранится 7 дней. Лог Xcode сохраняется отдельно.

Для scheme используется имя `GeckoRush`, потому что штатный экспортёр заменяет имя проекта/схемы на basename выходного пути `GeckoRush.xcodeproj`. Runner выбран `macos-15-intel`; universal-редактор Godot не привязан к архитектуре Mac runner.

## Почему указан Team ID 0000000000

Godot требует непустое поле Team ID даже при экспорте только файлов проекта. Во временной копии используется **явный placeholder `0000000000`**. Это не идентификатор пользователя, не сертификат Apple и не подпись. Перед вызовом Xcode значение Team дополнительно очищается параметром `DEVELOPMENT_TEAM=`.

Постоянный `export_presets.cfg` не получает вымышленные данные подписи. Workflow не входит в Apple ID и не обращается за сертификатами. У текущего GDScript-проекта нет нативных `.dylib`/GDExtension; добавление таких библиотек или iOS-плагинов может потребовать изменения процесса, потому что Godot на macOS выполняет предварительную подпись `.dylib` даже в режиме project-only.

## Повторная сборка вручную

1. Открыть публичный репозиторий с исходниками и включёнными Actions. Если создаётся новая копия, разместить workflow в её основной ветке; публикация исходников должна соответствовать разрешению владельца.
2. Выбрать **Build unsigned iOS IPA (manual)** → **Run workflow** и нужную ветку. В публичном репозитории используется бесплатный стандартный облачный Mac; в частном репозитории job пропускается.
3. Дождаться успешного завершения всех стадий. При ошибке прочитать лог; наличие зелёного этапа экспорта Xcode само по себе ещё не подтверждает сборку IPA.
4. Скачать артефакт **GeckoRush-unsigned-ipa**, распаковать внешнюю ZIP-обёртку GitHub и найти внутри `GeckoRush-unsigned.ipa` и `build-info.txt`.

При тайм-ауте, изменении образа Xcode или ошибке совместимости workflow завершится ошибкой и не выдаст вместо IPA архив исходников. Результат каждого нового запуска нужно проверять отдельно; успешный запуск 12 ноября подтверждает текущий рецепт, но не гарантирует совместимость будущего образа Xcode.

## Подпись и установка с Windows

**Unsigned IPA не устанавливается на обычный iPhone без подписи.** Передайте полученный файл выбранному локальному инструменту Sideloadly/AltStore и следуйте его официальной инструкции для Windows. Он выполняет подпись и установку с использованием вашей учётной записи Apple. Совместимость приложения и ограничения конкретного способа установки нужно проверить на устройстве.

Для Sideloadly на Windows: подключите разблокированный iPhone кабелем, подтвердите доверие компьютеру, выберите устройство, перетащите IPA в окно программы, укажите Apple ID и нажмите **Start**. При запросе iOS подтвердите профиль в **Настройки → Основные → VPN и управление устройством** и включите **Режим разработчика** в разделе конфиденциальности и безопасности.

При бесплатном Apple ID подпись действует **7 дней**. Затем повторите подпись и установку через Sideloadly с тем же Apple ID, не удаляя игру. Для самой игры после установки компьютер не нужен.

Apple ID, пароль, коды двухфакторной аутентификации и сертификаты вводятся **только у вас**, в выбранном инструменте/интерфейсе Apple. Их не нужно отправлять в чат, добавлять в репозиторий или записывать в GitHub Actions.

Эта схема получает исполняемое приложение без собственного Mac, но сама по себе не создаёт подписанный релиз для App Store/TestFlight.

## Выполненные проверки

Локально прошли проверка структуры YAML (в том числе единственного ручного trigger, разрешений, тайм-аута и фиксированных версий actions), `bash -n` для всех shell-фрагментов, компиляция встроенного Python и проверка синтаксиса helper через Godot 4.6.3 `--check-only`. Helper также запущен на отдельном тестовом проекте: нужные параметры появились во временном пресете, а SHA-256 исходного `export_presets.cfg` не изменился. Этот тест проверяет настройку конфигурации и не выполняет iOS-экспорт.

На облачном `macos-15-intel` выполнены полный `xcodebuild` для SDK `iphoneos` и упаковка IPA. После скачивания независимо проверены ZIP CRC, метаданные `org.geckorush.game` / 2.2.0 (4), исполняемый **arm64 Mach-O MH_EXECUTE** для iOS device, минимум iOS 14 и отсутствие подписи/профиля Apple. Это не приложение симулятора.

Игровой PCK Godot 4.6.3 содержит **39 записей** с проверенными MD5; все **12 скомпилированных игровых скриптов** побайтно совпадают с замороженным Android APK 2.2. В `Info.plist` включён `CADisableMinimumFrameDurationOnPhone`, позволяющий использовать высокий лимит кадров на подходящем iPhone. Установка, звук, сенсор, safe area и реальные 60/120 FPS на телефоне ещё требуют проверки.
