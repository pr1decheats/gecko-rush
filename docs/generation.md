# Генерация и ритм Android 2.2

Масштаб 64 px/м. Стены x270/810, игрок x296/784. Базовая дневная скорость 820 px/s, 1320 на250м, 2200 на 1000 м и ограничение 2700 на 2000 м. Прыжок 0,24 с с аркой 45 px. Отображаемые метры растут вдвое медленнее версии 2.0.

День 40 с, ночь 20 с. На 36–40 с скорость и фон плавно переходят к ночным. Вся фаза 40–60 с имеет фиксированную скорость 840 px/s независимо от высоты. На 60–64 с фон светлеет, а скорость плавно возвращается к дневной. Пауза замораживает часы. UI, фон и движение используют один RushTuning.

Первые1050px свободны. До200м идут чередующиеся ячейки1060/1100/1080/1040px без breathing; затем1120px. Intro envelopes зажаты между консервативными границами прыжка и следующей ячейки. Семь структур перемешиваются локальным Fisher–Yates deck без повторов на границе колод. Присутствуют одиночные настенные группы, отдельные центральные опасности, разнесённые по высоте пары, ступеньки, маленькие острова, настенные заросли и маятники. После двух секций с одной стороной маршрут меняется; каждая одиннадцатая секция даёт короткий просвет.

Опасности: шипы, камень, насекомое, пила, электрическая палка, падающий камень, кристалл, маятник и колючая лоза. Временные шипы открываются с уровня 8. Наборы зависят от мира; недавние центральные виды исключаются из очередного выбора, пока остаются альтернативы.

Безопасный путь проверяется по полным swept envelopes всех фаз движущихся опасностей, полному прямоугольнику перелёта при 2700 px/s и радиусу30 вместо игрового20. Это покрывает и замедленную ночь. Для половин высоты шипов геометрия строится точно по фактическому размеру. Рендер мелких опасностей согласован с радиусом столкновения. Непроверенная комбинация удаляется; встроенные структуры в 4680 проверенных ячейках не требовали удаления.

## Центральная стена

Каждые 1500 м отдельный детерминированный RNG делает выбор с вероятностью 50%. Предупреждение мигает 1,6 с в обоих случаях. Неуспех плавно исчезает за0,5с. Успех переводит игрока к ближайшей грани стены x512…568 за0,45с и скрывает боковые стены. Сам подъём длится ровно5с без опасностей, монет и мух. Последняя1с рисует трещины; затем стена разрушается на48 осколков и игрок за0,5с возвращается на исходную боковую стену. Во время автоматического переноса/передышки нажатия не вызывают случайного прыжка.

`begin_safe_section` удаляет уже созданные опасности и запрещает новые в защищённом интервале. Конец интервала рассчитывается по настоящей высоте/ночной скорости вперёд; максимальная скорость не используется как грубый запас, чтобы ночью не оставались десятки лишних пустых секунд. Удаляются полные пересекающиеся shapes с запасом. Движение осколков — отдельная ограниченная визуальная система, без влияния на генератор.

Snapshot course version4 сохраняет RNG строкой, колоду схем, недавние виды, safe_sections и маршрут. Checkpoint run schema4 дополнительно сохраняет стадию центральной стены и её время. Старые активные забеги закрываются со старым pixels_per_metre; постоянный прогресс сохраняется. Кэш геометрии строится при создании/restore, обслуживание массивов через512px, отрисовка раз за кадр.

Монета — вводная, далее84% в каждой четвёртой ячейке (~раз в83м при новой метрике). Мухи встречаются раз в три ячейки, если нет монеты, и съедаются один раз. Защищённая центральная секция подавляет оба вида.

Электрические палки имеют capsule radius10 (малые острова11), совпадающую с видимым core. Три слабые внешние дуги декоративные и не расширяют collision. Четыре текстуры разряда кэшированы. collision_kind_at возвращает тип после точного столкновения; main выбирает обычную смерть или1.4секэлектросмерти с44частицами пепла.
