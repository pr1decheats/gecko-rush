# Gecko Rush 2.8 — сборки и проверка

Версия **2.8.0 (10)**, Godot **4.6.3**. Исправлены рывки геккона и резкий переворот в прыжке. Персонаж, камера и движущиеся опасности используют общий визуальный момент между физическими шагами. Коллизии и сохранения используют прежние физические координаты.

Стены шести миров получили текстуры 270 × 320 вместо 135 × 160, по шесть вариантов кладки, новые грани и материалы. Переработаны все 24 тематических препятствия и узкая сейв-стена; игровые размеры сохранены.

Проверено 21 headless-набором (85 722 проверки), 15 766 headless и 15 782 native проверками движения. Дополнительно: 2092 проверки персонажа, 1480 проверок стен, 295 проверок препятствий и льда, 35 снимков интерфейса. Автоматически работающая main.tscn подтверждает движение между физическими тактами. Сравнение с 2.7 — 118 полных физических снимков за 13 919 тактов, сохранение и награды — не нашло различий. Все 25 файлов runtime совпадают с зафиксированными исходниками.

APK подписан прежним сертификатом: ARM 32/64, API 24/36, без запрошенных разрешений. Проверены CRC и 16 КБ выравнивание ZIP/ELF. Все 13 игровых GDC и 8 ресурсов брендинга побайтно совпадают во всех трёх пакетах. PCK проверен по MD5; экспортированный runtime прошёл 153 проверки. Windows CI запустил точный release EXE на 360 headless-кадров (6 симулированных секунд), exit 0. EXE не имеет подписи Authenticode.

IPA собрана для arm64 iPhoneOS стандартным бесплатным GitHub-hosted macOS runner в проверенном публичном репозитории. Apple credentials не использовались.

Все три пакета независимо скачаны из draft release: размеры, SHA-256 и CRC совпали. Публичные скачивания проверяются после публикации.

Обновляйте Android поверх прежней игры, Windows ZIP распакуйте в новую папку, сохраняя пользовательские данные. На iPhone используйте Sideloadly с тем же Apple ID и автоматическим Bundle ID, не удаляя игру. Бесплатная подпись Apple действует 7 дней. Скины, покупки, опыт и рекорды сохраняются.

Установка, звук и производительность на физических Android/iPhone не проверялись. Нативные кадры получены на программном Mesa; фактические 120/240 Гц дисплея не измерялись. Windows проверен в headless, без GPU-проверки.
