# Android 2.5.0 (7) — сборка ожидается

**GeckoRush-2.5.apk собирается; фактические параметры готового пакета ещё ожидаются.** Планируемая прямая загрузка после проверки и публикации: [GitHub Release v2.5.0](https://github.com/pr1decheats/gecko-rush/releases/download/v2.5.0/GeckoRush-2.5.apk).

| Параметр | План / фактический статус |
|---|---|
| versionName / versionCode | Целевые `2.5.0` / `7` |
| Размер | `PENDING_V25_APK_SIZE` |
| SHA-256 | `PENDING_V25_APK_SHA` |
| Подпись, ABI/API, CRC и 16 KB alignment | Новая проверка ожидается |

Нужна отдельная проверка готового APK: прежний сертификат для совместимого обновления, Release без отладки, разрешения, ABI/API, подпись v2/v3, CRC и ZIP/ELF alignment. Прежние успешные результаты 2.4 не перенесены на 2.5. Закрытый ключ и пароли остаются вне репозитория.

Реализована компактная заставка Triada Games: **55% ширины экрана**, fade-in **0,7 с**, удержание до **2,0 с** и fade-out до **2,5 с**. Только символ вращается со скоростью **6°/с**; `TRIADA` над `GAMES` остаются неподвижными. Пропуск разрешён после **0,3 с**. Нативная заставка движка и пресет iOS используют новый `assets/triada-games-launch.png` **1080×1920**: компактный первый кадр с **18% непрозрачности**, вписанный с сохранением пропорций; минимальный показ движка — **100 мс**. Исходный `triada-games.png` не изменён. Сосульки уже увеличены до 30,24×110 px и отдельно проверены. Boot-тест (21) и нативная регрессия брендинга (29) прошли без ошибок; упаковка графики в новый APK ещё не проверена; ожидается дополнительный `boot.gdc` и **13 игровых `.gdc`** всего.

[Текущие поля сборок](builds.md), [план проверок](validation.md), [экспорт](mobile-export.md). Android 2.5 на физическом устройстве не проверен.
