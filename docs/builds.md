Распакуйте ZIP и запустите `GeckoRush/GeckoRush.exe`. Игровые данные встроены в EXE; редактор Godot не нужен. В архиве также README и лицензии. Проверены PE64, подпись встроенного PCK и CRC ZIP. На самой Windows/Wine исполняемый файл не запускался; для проверки самостоятельного экспорта собран и запущен Linux-вариант.

## Android

Пакет `org.geckorush.game`, versionCode **2**, versionName **2.0.0**, minSdk **24**, targetSdk **36**. Официальный release-шаблон Godot4.6.3, Compatibility/OpenGL ES3, `arm64-v8a` и `armeabi-v7a`. Подписан тем же тестовым ключом, что версия1.0; может обновить её без удаления данных. Это тестовая подпись для установки вручную, не магазинная подпись Google Play.

Проверены `apksigner verify` (v2/v3), `zipalign -c -P16`, ZIP CRC, обе нативные библиотеки, новые скрипты и лицензии. Сайт перед сохранением восстанавливает файл из статических частей и проверяет SHA-256; результат побайтно совпадает с оригиналом. Версионные имена и отсутствие кэширования частей предотвращают выдачу прежнего APK.

SHA-256 APK:

```text
daea961fe34c9d7b0c30bbd5076f5ed9f09b4ef20e9955512dece0fca1f45c25
```

На настоящем Android/эмуляторе приложение пока не запускалось. Частота60/120FPS меняется в настройках; на Android11+ поддерживаемому экрану отправляется системный запрос через Surface.setFrameRate. Это не измерение FPS: реальная частота зависит от устройства и системных ограничений. Старые/неподдерживаемые устройства используют60FPS.
